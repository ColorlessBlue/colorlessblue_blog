This is where my literary writing would live. I write it in Chinese, and too much of what it is belongs to the language itself — its sound, its rhythm, the histories a single character carries. I have never found a translation that does not dissolve it, so I have left it untranslated.

If you read Chinese, you can find it here, in the [original version of this blog](/colorlessblue_blog/blog/).
